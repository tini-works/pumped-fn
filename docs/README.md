# Pumped-fn Cheat Sheets

This directory contains cheat sheets for the pumped-fn packages:

## Available Cheat Sheets

- [Core Package (@pumped-fn/core-next)](./core-next-cheatsheet.md) - The core state management functionality
- [React Package (@pumped-fn/react)](./react-cheatsheet.md) - React bindings and components
- [Extra Package (@pumped-fn/extra)](./extra-cheatsheet.md) - Additional utilities for full-stack applications

## Overview

Pumped-fn is a functional state management library for TypeScript applications. It provides a powerful and flexible way to manage state with a focus on:

- Type safety
- Composability
- Reactivity
- Testability

The library is split into multiple packages to keep dependencies minimal and allow for flexible usage in different environments.

## Getting Started

To get started with pumped-fn, install the packages you need:

```bash
# Core package
npm install @pumped-fn/core-next

# React bindings
npm install @pumped-fn/react

# Extra utilities
npm install @pumped-fn/extra
```

Then check out the cheat sheets for each package to learn how to use them effectively.
